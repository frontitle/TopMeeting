## TopMeeting 0.15.0 for Windows x64

Install the setup EXE once to enable future in-app updates. Open Settings → Software update to check, download, and restart when ready. Installation waits for recording, notes and document work to finish. The portable ZIP remains available for manual upgrades.

This preview includes the listening window’s End button, updated overlap handling, a single meeting document destination and the new app icon. Existing local meetings and voice profiles use the same data directory.

Download the installer or portable ZIP from this release. The installer is unsigned. The SHA-256 checksums cover both downloads. The updater reads latest.yml and verifies the installer’s SHA-512 before running it.
